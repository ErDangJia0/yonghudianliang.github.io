# 售电公司代理用户 · 分时电量与电价分析

纯前端（单文件 HTML + ECharts + SheetJS）电量 / 电价可视化分析工具，配合 Python 流式预处理脚本，可处理两种结构完全不同的 Excel 数据源。核心价值：**展示代理零售电价与国网基准电价的节省效果**。

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 分析页面（单文件，含全部 HTML/CSS/JS） |
| `generate_data.py` | Excel → `data.js` 预处理脚本（openpyxl 流式读取，自动识别数据模式和国网电价表头格式） |
| `data.js` | 预处理产物，页面通过 `<script src="data.js">` 加载 |

## 快速开始

### 1. 环境要求

- Python 3.8+（仅预处理需要）
- 依赖：`openpyxl`（`pip install openpyxl`）
- 现代浏览器（Chrome / Edge），首次打开需联网加载 ECharts、SheetJS CDN

### 2. 生成数据

```powershell
# 方式一：手动指定 Excel
python generate_data.py "C:\path\to\电量电价表.xlsx"

# 方式二：不带参数 —— 自动选取桌面和脚本目录下修改时间最新的 xlsx
#         （自动跳过 Excel 锁文件 ~$xxx.xlsx）
python generate_data.py
```

控制台会输出识别到的模式、sheet、企业数、月份、总电量和耗时，例如：

## 支持的两种数据模式

脚本按表头自动识别，无需手动切换。

### 模式 A：detailed（分时明细）

判定条件：某 sheet 含 ≥90 个 `HH:MM` 列。

- **电量 sheet**：每行 = 企业 × 日期 ×（计量点/户号）× 96 个 15 分钟时段列（表头 `00:15` … `24:00`），另有市场成员名称、日期、计量点、户号等列
- **电价 sheet**：月份 + 企业 + 24 个小时电价列（表头为数字 `1`…`24`，单位 元/MWh）
- **国网电价 sheet**（可选但推荐）：sheet 名含"国网"但不含"费用"。表头支持两种格式：
  - 数字 `1`…`24`（新格式，与电价 sheet 相同）
  - 时间范围 `HH:MM-HH:MM`（旧格式）
- **国网其他费用明细 sheet**（可选）：sheet 名含"费用"。第 1 列为月份（`1月`），其余每列为一种费用，表头标注"元/兆瓦时"（如上网环节线损折价、电量输配电价、政府性基金及附加、系统运行费用）
- 参考数据量：4 万行 ~ 15 万行，流式读取约 15~70 秒

**时段口径**：`HH:MM` 列表示时段**结束时间**。聚合到小时时按 `hour = floor((HH:MM − 15min) / 1h)` 归并，每个小时恰好包含 4 个 15 分钟时段（如 `00:15/00:30/00:45/01:00` → 0 点，`23:15/23:30/23:45/24:00` → 23 点）。

### 模式 B：settlement（结算汇总）

判定条件：某 sheet 同时含"结算电量"和"结算电价"列。

- 单 sheet，每行 = 月份 × 企业 × 联系人 × 结算电量(MWh) × 结算电价(元/MWh) × 结算方案
- 无小时粒度数据，页面自动切换为简化视图（仅电量 / 电价 / KPI）
- 无国网电价对比图

## 页面功能

### 总览区

- 6 张统计卡：代理企业数、累计总电量、**市场零售电价**（= 全时段电量加权均价）、日均/月均电量、计量点数（或结算周期）、前 10 企业电量占比
- 企业用电排名表（支持名称搜索，按总电量降序）
- 全局 96 时段平均负荷曲线（仅 detailed）

### 企业详情

点击排名表中的企业进入，**默认显示全部视图**。顶部月份切换按钮可在「全部 / 各月份」间切换。

#### detailed 模式

**KPI**：电量、零售电价、日均电量、**最大负荷**（MW，15min 电量 × 4；多个峰值点同时列出）、计量点/户数

**全部视图（月度汇总）**：

| 组件 | 内容 |
|---|---|
| 6 列表格 | 月份 · 电量(MWh) · 零售电价 · 国网电价 · **度电节省**（元/MWh）· **节省费用**（万元）|
| 合计行 | 全部月份加权重算（不是各月简单相加），电量加权：`Σ(hourE×price) / Σ(hourE)` |
| 3 系列组合图 | 🟦 电量 MWh（柱）· 🟠 零售电价（阶梯线）· 🔴 国网电价（阶梯线），双 Y 轴 |

**单月视图**：

| 组件 | 内容 |
|---|---|
| 电价 · 电量对比 | 🟦 小时电量 MWh（柱）· 🟠 零售电价（阶梯线）· 🔴 国网电价（阶梯线），双 Y 轴，ECharts 共 3 series |
| 加权电价 + 节省合计表 | 当月总电量 · 零售加权电价 · 国网加权电价 · **度电节省**（国网 − 零售）· **整体节省费用**（万元）|
| 每日总电量 | 仅显示当月日期的每日电量柱状图（全部视图则显示所有日期） |
| 国网其他费用明细 | 见下文（全部 / 单月视图均显示） |
| 96 时段负荷曲线 | 15min 粒度的小时负荷 |

**度电节省与节省费用计算**：
```
零售加权电价 = Σ(hourE[h] × retailPrice[h]) / Σ(hourE[h])   # 仅 price 非 null 小时
国网加权电价 = Σ(hourE[h] × gridPrice[h]) / Σ(hourE[h])
度电节省     = 国网加权电价 − 零售加权电价                   # 正数 = 零售更便宜，绿色；负数红色
整体节省费用 = 度电节省 × 当月总电量 / 10000                 # 单位：万元
```

> 月度汇总的合计行同样按小时粒度加权重算，避免不同月电量权重被忽略。

**月度补全**：企业缺失的月份在月度汇总表中按电量 0 显示（空月对象，电价 null），不影响图表其他月份的正常展示。

**国网其他费用明细**（数据源：sheet 名含"费用"，列为各费用项、表头标注"元/兆瓦时"）：

位于"每日总电量"图下方，为全市场统一的月度数据（不随企业切换变化），全部视图与单月视图均显示：

- **堆叠柱状图**：固定费用（各月不变，如电量输配电价、政府性基金及附加）用冷色堆积在**下方**；月度变化费用（如上网环节线损折价、系统运行费用）用暖色堆积在**上方**
- 柱顶标注当月各项费用合计；红色虚线 markLine 标注全部月份的合计均值
- 顶部 chips：每项标注"固定"或"月均"值 + 月均合计
- 下方明细表：9（N）个月 × 各费用项 + 月合计，末行为各项月均与总均值；数字全部居中、等宽数字（tabular-nums）、斑马纹与 hover 高亮，月合计列淡蓝底色强调（窄屏可横向滚动）
- 均值口径：同类费用对全部月份求均值；月度合计为当月各项求和，总均值为月度合计的月均
- 固定项判定：同项费用全部月份 `max − min < 0.001` 即视为固定，自动排序到堆积层下方

#### settlement 模式

简化视图，不显示分时和国网电价对比：
- KPI：电量、零售电价、月均电量
- 月度结算明细表
- 月度电量柱 + 零售电价线

### 浏览器直传（小文件）

页面顶部支持拖拽 / 选择 Excel 直接解析（SheetJS）：

## 数据口径与单位

| 项目 | 单位 | 备注 |
|---|---|---|
| 电量 | MWh | 分时槽为 MWh/15min；**页面统一保留 3 位小数** |
| 电价 | 元/MWh | 零售电价 = 代理用户电价；国网电价 = 电网基准；**统一保留 1 位小数**（含图表 tooltip）|
| 其他费用 | 元/MWh | 国网其他费用明细，统一保留 1 位小数 |
| 最大负荷 | **MW** | 原始 15min 电量 × 4（物理换算：1 个 15min 槽满功率 = 4×MW 持续 1h）|
| 节省费用 | **万元** | 度电节省 × 电量 / 10000，保留 2 位小数；正数表示零售更便宜 |
| 度电节省 | **元/MWh** | 国网加权电价 − 零售加权电价，保留 1 位小数 |

日期列兼容三种格式：Excel 日期对象、Excel 序列号（>20000 的数值，按 1899-12-30 基准换算）、`YYYY-MM-DD` 字符串。电价列中的非数值内容（如联系人文本残留）自动跳过为 `null`。

### 最大负荷多点追踪

脚本在遍历 15min 槽时，同时追踪全局和 per-month 维度下**所有等于最大值的点**（相对误差 < 0.1%），去重后上限 5 个。前端 KPI 根据点数显示：

- 1 个点：`5.76 MW 出现于 2026-01-20 10:45`
- 多个点：`4.32 MW 出现于 2026-01-01 00:30、2026-01-08 10:45 等 5 个点`

## 常见问题

**Q：提示 `ValueError: could not convert string to float`？**
旧版脚本按分时结构硬读汇总表会出现此问题；当前版本已按表头自动识别模式。若仍报错，请确认表头包含"结算电量""结算电价"或 96 个 `HH:MM` 列。

**Q：国网电价全 null？**
请确认 Excel 中 sheet 名含"国网"二字。表头支持两种格式：数字 `1`~`24` 和时间范围 `HH:MM-HH:MM`。若两种都不是，脚本会跳过该 sheet 且控制台不会报错（正常日志仅显示 `grid_price 9 months from sheet '国网电价'`）。确认表头是数字还是时间范围后可加一行 debug。

**Q：60 MB 大文件页面上传解析失败？**
浏览器仅支持 ≤15 MB 文件直传。大文件请运行 `python generate_data.py` 预生成 `data.js` 后刷新页面。

**Q：换了新月份的数据怎么更新？**
重新运行一次 `generate_data.py`（指向新 Excel），刷新浏览器即可，无需改动页面。

**Q：换文件后页面没变化？**
浏览器对 JS 文件有缓存。**Ctrl+Shift+R** 强制刷新，或在地址栏加 `?ts=时间戳` 参数绕开缓存。

**Q：第一个 / 最后一个小时电量异常？**
已修复。时段列为结束时间口径，小时聚合使用 `floor((HH:MM − 15min) / 1h)`，每小时严格 4 个槽，避免 0 点少算、23 点多算。

**Q：企业月度表有的月份电量为 0？**
这是正常行为：该企业当月确实没有用电数据时，脚本按 0 填充，不跳过该月。

**Q：最大负荷出现好几个日期？**
脚本追踪所有等于最大值的 15min 槽（相对误差 < 0.1%）。如果企业每天同一时段用电量刚好相等（比如恒定生产模式），会有多个峰值点同时被记录，KPI 中显示"等 N 个点"。

**Q：节省费用是负数？**
负数表示**代理零售电价反而比国网基准价高**。脚本不做绝对假设，正负由实际电价数据决定。

**Q：没有"国网其他费用明细"图？**
需 Excel 中存在 sheet 名含"费用"的工作表，且费用列表头标注"元/兆瓦时"（或"元/MWh"）。正常日志为 `[grid_fees] 9 months, 4 items from sheet '国网其他费用明细'`；无此 sheet 时面板显示"无国网其他费用明细数据"。
